Guia de implantação: planilha de leads + publicação no GitHub Pages

Passo a passo pra conectar o formulário da LP a uma planilha do Google Sheets e publicar o site no ar, no mesmo padrão usado na Kibune e na Blanc.

1 Criar a planilha e o Apps Script

Vai registrar cada lead (nome + WhatsApp) automaticamente numa planilha do Google.

  1. Acesse sheets.new pra criar uma planilha do Google Sheets em branco. Renomeie pra algo como "Leads BildS LP".
  2. Na linha 1, crie os cabeçalhos, um por coluna: A1: Data e hora · B1: Nome · C1: WhatsApp · D1: Origem.
  3. No menu, vá em Extensões → Apps Script. Vai abrir um editor de código numa aba nova.
  4. Apague o conteúdo padrão (function myFunction(){}) e cole o código abaixo — ele também está no arquivo google-apps-script/Code.gs dentro do zip da LP.
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);

    sheet.appendRow([
      new Date(),
      data.nome || '',
      data.whatsapp || '',
      data.origem || 'LP BildS Odontologia'
    ]);

    return ContentService
      .createTextOutput(JSON.stringify({ status: 'ok' }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'erro', mensagem: err.message }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Salve (ícone de disquete ou Ctrl+S) e dê um nome ao projeto, ex: "BildS LP Leads".
  2. Clique em Implantar → Nova implantação.
  3. No ícone de engrenagem ⚙, escolha o tipo "Aplicativo da Web".
  4. Configure: Executar como: Eu (seu e-mail) · Quem pode acessar: Qualquer pessoa (essencial — sem isso o formulário não consegue enviar dados).
  5. Clique em Implantar e autorize as permissões pedidas (é o seu próprio script, pode confirmar).
  6. Copie a URL do app da Web gerada (termina em /exec).
Se você editar o código depois de já ter implantado uma vez, é preciso ir em Implantar → Gerenciar implantações → ícone de lápis → Nova versão → Implantar. Senão a URL antiga continua rodando o código antigo.

2 Conectar a URL na LP

  1. Abra o arquivo index.html (dentro da pasta da LP) em qualquer editor de texto.
  2. Procure a linha: var SHEETS_WEBAPP_URL = "";
  3. Cole a URL copiada no passo anterior entre as aspas, assim: var SHEETS_WEBAPP_URL = "https://script.google.com/macros/s/SEU_ID/exec";
  4. Salve o arquivo.

3 Publicar no GitHub Pages

Coloca a LP no ar com um link público, gratuito, no mesmo esquema da Kibune e da Blanc.

  1. Extraia (descompacte) o arquivo BildS-LP.zip no seu computador — vai virar uma pasta com o index.html e a pasta assets/ dentro.
  2. Acesse github.com e faça login com a mesma conta que você já usa (DougLP7).
  3. Clique em New (ou acesse github.com/new) pra criar um repositório novo.
  4. Dê um nome, por exemplo Clinica-BildS. Deixe marcado como Public (necessário pro GitHub Pages gratuito) e clique em Create repository.
  5. Na página do repositório vazio, clique no link azul "uploading an existing file".
  6. Arraste para lá todo o conteúdo de dentro da pasta extraída (o index.html e a pasta assets/) — não o .zip em si.
  7. Aguarde o upload terminar (os vídeos são maiores, pode levar um minuto) e clique em Commit changes.
  8. Vá em Settings → Pages (menu lateral esquerdo).
  9. Em Source, selecione a branch main e a pasta / (root), depois clique em Save.
  10. Aguarde 1–2 minutos e atualize a página — o GitHub mostra o link no formato https://douglp7.github.io/Clinica-BildS/.
Teste o link direto no celular antes de rodar tráfego: confira o formulário, os vídeos e o botão de WhatsApp.
